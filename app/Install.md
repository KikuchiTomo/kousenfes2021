# 環境構築手順

## 必須設定
 - Github
 - ペア鍵の作成(RSA:2048>)
 - VSCodeの設定
 - WinSCPの設定

## Github
### アカウントの作成
[GitHub.com](https://github.co.jp/)でアカウントを作る。名前はわかりやすく、本名がよい。
### Gitツールのダウンロード

## VSCodeの設定
### VSCodeのインストール
#### VSCodeインストーラのダウンロード
VSCode(Vidual Studio Code)がインストールされていない場合には、[VSCode](https://azure.microsoft.com/ja-jp/products/visual-studio-code/)にアクセスして、`Download now`より自分の環境にあった物をダウンロードする。
#### インストール
インストーラをダブルクリックしてインストールする。　
#### 拡張機能の追加
VSCodeを起動させたら、左端にある□が欠けているマークを選択。検索窓に、`GitHub Pull Requests and Issues`といれ、同じ名前の物をインストールする。  
同様にして、以下の拡張機能もインストールする。  
 - HTML Snippets
 - Jaoanese Language Pack for Vidual Studio Code
 - Remote - SSH
 - Remote - SSH: Editing Configuration Files
